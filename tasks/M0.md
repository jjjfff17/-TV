# 任务书 M0：Flutter 骨架 + 原生播放链路验证

## 一、背景
LibreTV 决定走「完整原生（Android）」路线，播放内核选 media_kit（libmpv）。M0 的唯一目的是**证明链路通**：能出包、能装上、能播、不崩。不做业务功能。

## 二、目标
- 一个 Flutter 工程，启动即进入播放页，播放一条测试 HLS。
- GitHub Actions 自动构建 release APK 并上传 artifact。

## 三、输入
- `PROJECT.md`（事实基准）
- `CHECKLIST.md`（CL-NAT-01/03/05/07 适用）

## 四、输出要求
- `lib/main.dart`：初始化 `MediaKit.ensureInitialized()`。
- `lib/screens/player_screen.dart`：播放 + 播放/暂停 + 进度条 + 时间 + 倍速菜单 + 全屏横屏。
- `.github/workflows/build-apk.yml`：`flutter create` 生成 android → 复制 `lib/` 与 `pubspec.yaml` → patch manifest → `flutter build apk --release` → 上传 APK。

## 五、验收标准
- [ ] CI 绿色，artifact 里有 `app-release.apk`
- [ ] 装上能打开，不闪退
- [ ] 测试流能播放、能暂停、能拖进度
- [ ] 全屏按钮能把画面转横屏，退出恢复竖屏
- [ ] 错误时不崩，屏幕上有可读提示

## 六、反例（不要做）
- ✗ 在 M0 就写首页/搜索/详情（属于 M1，跨阶段）
- ✗ 忘记 `MediaKit.ensureInitialized()`，启动即崩（CL-NAT-03）
- ✗ manifest 不加 INTERNET，播放黑屏（CL-NAT-01）
- ✗ 直接在本机跑 `flutter build`（本机无 SDK，必失败）

## 七、禁止事项
- 不改 `PROJECT.md` 的事实基准；不做全局决策；卡住就停下报告。
